## Executive summary

GreyVerse is a football gaming competition platform built around organized online play, leagues, fixtures, rankings, tournaments, player profiles, match verification, reporting, rewards and game-specific competition contexts.

The acquisition includes the software source code, database/migration architecture, deployment configuration and product/IP assets currently contained in the repository.

This is a software asset/MVP acquisition, not a claim of an established revenue-generating business.

## Product concept

GreyVerse is designed for football-gaming communities that need more than a basic leaderboard. It combines player identity, organized league competition, fixtures, tournaments, rankings and match administration into one platform.

The architecture supports separate game contexts so competition rules and player participation can be organized by supported game.
