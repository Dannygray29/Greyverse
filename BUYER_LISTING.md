# GreyVerse — Buyer Listing

## Football Gaming & Esports Competition Platform

**Price:** $4,900 USD OBO  
**Stage:** Early-stage software asset / MVP  
**Category:** Gaming / esports / SaaS / community platform

### The opportunity

GreyVerse is a partially built football gaming competition platform designed to organize players, leagues, fixtures, rankings, tournaments and match administration in one product.

It is being offered as a software/IP asset for an operator, developer, gaming community or founder who wants an existing technical foundation rather than starting from a blank repository.

### Included in the acquisition

- Next.js / React / TypeScript application
- Supabase/PostgreSQL database architecture and migrations
- Authentication and player-profile flows
- Game-specific player contexts
- League, membership and fixture architecture
- Rankings and standings
- Tournament architecture
- Match-ready, result, evidence and dispute structures
- Notifications
- Rewards, wallet and transaction structures
- Reports and suspension structures
- RLS/security work and technical audit documents
- Capacitor Android configuration
- GitHub Actions/deployment configuration
- Source code and Git history

### Current state

GreyVerse is **not being represented as a mature revenue-generating business**. It is an early-stage software asset/MVP with substantial implementation already present and documented remaining validation work.

Known remaining work includes end-to-end testing of authenticated match workflows, result/dispute flows, game isolation, seasonal transitions, playoff edge cases and hardening of any remaining sensitive mutations.

### Best fit

This asset may suit a buyer who wants to:

- launch a football gaming league/community
- build an esports competition product
- adapt the code for another sports/game community
- use the backend architecture as a starting point
- acquire and rebrand an existing gaming platform

### Due diligence

Full technical documentation and audit files are included in the repository. Serious buyers can inspect the source before agreeing a transaction.

### Transaction

The seller is open to serious offers. Ownership/source transfer is subject to agreed payment and written transaction terms.
